## IntelliJ support helper

The Brikk-specific Kotlin host and interpolation behavior consolidates Apache-2.0
work from `sort-dev/duckdb-intellij-plugin` at
`8a8f1f7da7ec2df09dbea43a510c9c07af2c1024` and
`sort-dev/doris-intellij-plugin` at implementation commit `fbfc50c`, release
reference `9e7cb99`. The helper is excluded from the root Business Source
License and stays Apache-2.0 under its own
[LICENSE](brikk-engine-kotlin-intellij-support/LICENSE) and
[NOTICE](brikk-engine-kotlin-intellij-support/NOTICE), so the Apache-2.0
dialect plugins can embed it. IntelliJ/Kotlin IDE binaries are compile/test inputs
only, not bundled runtime contents. General SQL code remains in the dialect plugins.
